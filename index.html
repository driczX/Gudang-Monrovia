Setup Firebase — sekali saja

Paste konfigurasi Firebase kamu di bawah ini. Bisa didapat dari Firebase Console → Project Settings → Your apps → Web app → Config.

Cara dapat config:
1. Buka console.firebase.google.com
2. Pilih project → ⚙ Project Settings
3. Scroll ke "Your apps" → klik ikon Web (</>) → Register app
4. Copy bagian firebaseConfig = { ... }
